# Omega Codon — playable prototype
スマホのブラウザで遊べる、進化シミュレーションの試作版です（ビルド不要・外部ライブラリなし・通信なし）。
セーブはブラウザ内（localStorage）にだけ保存されます。

## 地球編・中間版（Stage 2.0）
- 時間は可変です。1ステップを30日とみなし、平穏な期間は世界の時計（年）だけを大きく進めます。その間、生き物は進化しません（画面の「世界」タブに内訳と仮定を表示）。
- 知性文明が、生物圏・気候・資源・前の文明の跡から確率的に現れ、環境を変え、崩壊し、また現れます。
- 4つの方針（逃避・共存・防御・攻撃）と、操作する系統の切り替えができます。効き目は、その系統の能力と状況で決まります。
- 生き物の数は、アリーナの実個体10体＝1Uで表示します。世界全体の個体数は計算していません。
- 約10億年後に必ず全生命が絶えると決めているわけではありません。気候・文明・衝突の数値の多くはゲーム上の仮定です。
